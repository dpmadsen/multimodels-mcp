Você recebeu esta função de um app de divisão de contas (Node.js, CommonJS):

```javascript
function dividirConta(totalCentavos, pessoas) {
  const base = Math.round(totalCentavos / pessoas);
  const partes = [];
  for (let i = 0; i < pessoas; i++) partes.push(base);
  const sobra = totalCentavos - base * pessoas;
  partes[0] += sobra;
  return partes;
}
module.exports = { dividirConta };
```

Contrato da função: recebe o total da conta em centavos (inteiro >= 0) e o número de pessoas (inteiro >= 1); devolve um array com o quanto cada pessoa paga, em centavos, somando EXATAMENTE o total; a diferença entre qualquer par de pessoas deve ser de no máximo 1 centavo, e quem está no INÍCIO do array paga os centavos extras. Entradas fora do contrato devem retornar null (nunca lançar erro nem devolver NaN/Infinity).
