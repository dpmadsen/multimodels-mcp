`Math.round` pode arredondar a base para cima, tornando a sobra negativa; assim, o primeiro recebe uma subtração (ex.: 5/2 vira `[2, 3]`).  

Sem validação, `pessoas = 0` produz cálculos com `Infinity`/`NaN`, devolvendo valores inválidos em vez de `null`.

```javascript
function dividirConta(totalCentavos, pessoas) {
  if (
    !Number.isSafeInteger(totalCentavos) ||
    totalCentavos < 0 ||
    !Number.isSafeInteger(pessoas) ||
    pessoas < 1
  ) {
    return null;
  }

  const base = Math.floor(totalCentavos / pessoas);
  const sobra = totalCentavos % pessoas;
  const partes = Array(pessoas).fill(base);

  for (let i = 0; i < sobra; i++) {
    partes[i]++;
  }

  return partes;
}

module.exports = { dividirConta };
```
